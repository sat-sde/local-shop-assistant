### The one real bug — found and fixed

**What it was:** When a user uploaded their own CSV via the sidebar, `load_data()` received a Streamlit `UploadedFile` object but tried to call `os.path.exists()` on it — which always returns `False` — causing a crash every time.

**Fix:** `data_loader.py` now checks whether `source` is a string path or a file-like object, and skips the `os.path.exists()` check for uploaded files. `pandas.read_csv()` already handles both natively.
